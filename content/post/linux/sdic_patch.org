** sdicを修正
sdicは土屋さんのとこにあります。
[[http://www.namazu.org/~tsuchiya/sdic/#download][http://www.namazu.org/~tsuchiya/sdic/#download]]


./configureしないとsdic.elが生成されないので注意!\\
またconfigureすると上書きされるので、下記修正を行ったときは注意!\\
permissionも+wすること!(他のelも)

- (a)文法chkがきつくなったそうな\\
  stem.el,sdic-compat.el,sdic-gene.elの
  '(lambdaとなっている  'を全部消去。\\
  つまり'(lambdaを(lambdaと修正！\\
  ,)も修正::全部削除

- (b) default-fill-column が未定義と怒られるので、setqします。

  #+begin_src emacs-lisp
  (if (not (boundp 'default-fill-column))
      (setq default-fill-column (default-value 'fill-column)))
  #+end_src

  または

  #+begin_src emacs-lisp
  (if (string-match "26" emacs-version)
      (setq default-fill-column (default-value 'fill-column)))
  #+end_src

  をsdic.el冒頭に追加
  [[http://tarancho.hatenablog.com/entry/2018/11/06/200511][こちらの情報です。]]\\
  コンパイルしないときは.emacsに書いてました。

** ispellを動かす,2023.hunspellを使う

本体と辞書をapt

#+begin_src shell
apt install hunspell
apt install hunspell-en-us
#+end_src

bashrcへの設定は不要でした。

1. 端末で使うとき

   -dで使用辞書を指定します。

   #+begin_src shell
   hunspell -D
   #+end_src

   で辞書サーチパスを示します。

2. emacsから使う。

   init.elに以下指定を追加します。

#+begin_src emacs-lisp
(setq ispell-program-name "hunspell")
(setq ispell-really-hunspell t)
(setenv "DICTIONARY" "en_US")
(setenv "WORDLIST" "$HOME/.hunspell_personal_dictionary")

;;ispell を使う場合、日本語混じりのファイルのスペルチェックをすることができます。
(eval-after-load "ispell"
 '(add-to-list 'ispell-skip-region-alist '("[^\000-\377]+")))
#+end_src
